## 范围

基线提交为 `09f1c0c362ecb094b29c8313d722bda40d3a54bc`。保留原有 wire、notgate、dff8r 三个公开规格 oracle，扩展剩余题目的 Host 网表检查。

新规则使用固定版本的参考实现和测试激励，单独生成稳定采样的检查器，不复用旧测试台的比较进程。GSR/GTS 释放后启动时钟和测试激励；除物理时钟和已审查的锁存器使能外，数据相对驱动事件延后 0.1 ns；每半周期在 0.5 ns 和 4.8 ns 采样。随机激励显式设定局部种子，不随 DUT 展开层级变化。参考输出明确为 X/Z 的位不作断言，但每个必检输出位必须至少出现一次已知值；DUT 在参考已知位输出 X/Z 会失败。第 94 题只对公开未规定的 out_both[3] 和 out_any[0] 豁免观察，不扩大到其他位。

激励生成器的反馈端口只连接参考输出，避免候选电路改变测试序列。一般负例在网表 DUT 输出端插入反相，不改变参考预期值。第 53 题使用公开状态递推检查，允许初值 0 或 1，采用恒零输出负例；输出反相仍可能满足该题递推关系，不能充当有效负例。该检查属于有限功能对照，不是形式等价，也不证明参考实现本身符合所有题意。
