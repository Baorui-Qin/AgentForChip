# 参考资料索引与阅读顺序


**本目录收录的是官方链接、原创阅读说明和用户原始截图，不是论文/手册全文镜像。** 正式离线运行不需要打开这些网页；需要的模型与工具资产应在开发期按许可另行取得。链接的主分支和 latest 会变化，提交时必须固定实际采用版本。

建议顺序：赛题 → UG900/UG901 → 人工 RTL 验证 → 本地推理部署 → VerilogEval → 反馈/技能算法 → 统计与消融。选择 HLS 后再优先读 UG1399、官方例程和 HLS-Eval。

## 使用这些资料时的边界

模型、数据集、手册、论文和第三方代码分别遵守原许可。本包的原创说明和代码不转移这些第三方权利。不要把论文中的最好结果、当前网页上的下载数或模型卡自述当作本方案的实测证据。

主张“在本赛道更好”需要同一模型/预算/工具/题集下的实验；主张“可以离线复現”需要真正关闭网络重跑；主张“单卡容纳”需要峰值显存和完整驻留记录。
