## Prob133 初始候选存在可直接证明的功能错误

候选 SHA-256：`c78f6081fc089dd57708244a73847f2309600a4857b99fc0195ee4a3106ad068`。题面要求在三个采样周期中恰好出现两个 `w=1` 才产生 `z=1`。

从 reset 状态 A 以 `s=1` 进入 B 后，连续采样 `w=0,0,1`。候选状态转换为 `B -> C0 -> D0 -> E1`，因为源码将 `D0` 写为 `w ? E1 : E0`，随后 `assign z = (state == E1)` 产生高电平。这里只出现一个 `w=1`，不符合公开题面。这是直接阅读原始候选得到的确定性反例，不是额外运行的仿真，也不依赖隐藏参考。

原批与续测对同一初始候选的真实验证均为 2,827 次检查、464 次失配。续测早期仍出现 `REPEATED_CANDIDATE` 工具拒绝，因此并非所有长循环都能归因于已知参考规格冲突。

候选见 [initial.sv](../generate-Prob133_2014_q3fsm/initial.sv)，逐题模型活动见 [完整记录](../analysis/Prob133_2014_q3fsm.md)。最终修复结果以独立续测报告为准。
