# Agent Note: P10 完整证据与模式安全恢复

Status: implemented

[English](2026-09-22-p10-evidence-recovery.md) | 中文

## 问题

大量小块组成的序列化流数组可能超出事件预算，但实际模型文本仍在响应预算内。把关闭思考的助手工具回合回放到思考模式会违反提供方对推理历史的要求。受限的诊断摘要和不包含源文件的展开调用可能掩盖完整的 DUT 失败证据。

## 决策

[P10 repair-v3](../../../../rtl-tools/phase1/p10/README.zh.md#repair-v2)保留增量转录，分别限制响应文本、token 和时间，不把流块封装开销作为限制。Host 将最近的工具观察投影到已记录的事实核心，并从后续思考请求中排除关闭思考的历史。它既不合成推理，也不丢弃动作拒绝记录。

诊断读取器重新解析完整的已保留日志，并跨阶段使用同次运行的精确信任源路径。狭窄的过程驱动规则只识别 DUT 主错误及完全匹配的同次调用 XSIM 摘要。所有独立未知错误仍阻塞。显式 100 题模式要求冻结清单及已校准选题；拒绝详情和校准排除项与 RTL 功能失败分开记录。

## 考虑过的替代方案

**提高所有上限。** 这会掩盖封装计量缺陷并改变实验的模型预算。现有响应、token 和超时上限保持不变。

**全面忽略不完整摘要或未知展开错误。** 原始日志缺失、资产损坏、解析器溢出和独立错误仍使证据无效。只有经验证的原始证据或严格识别的后继消息组才能恢复修复资格。

**在历史中插入人工推理。** 这会伪造模型输出。新请求改用 Host 事实，原始响应仍保留在归档中。

## 影响

事实核心携带最近的工具结果，包括拒绝记录和检索到的技能数据，因此压缩不能静默删除最近的观察。这会消耗提示空间，仍可能超过必要核心预算。历史记录不可变；回放仅用于诊断。必须通过新实验测量准确率影响。

## 测试

定向回归覆盖大流块封装、响应字节上限、强制动作拒绝和恢复、工具结果保留、仅摘要截断、日志缺失、进程日志截断、解析器溢出、资产损坏、不含源文件的展开、异次调用摘要和未知错误。显式数量测试保留默认十题权限，并拒绝超过 100 题。真实 API 行为和准确率在已授权的冻结实验中另行测量。
