# 100 题 Baseline / Agent 测试结论

日期：2026-09-22。最终比较目录：`D:/AMD/p100-0922-c3`。实际运行于当日 23:06（北京时间）结束，执行器退出码为 0，临时防自动睡眠请求已释放。没有未启动的合法候选或待处理的基础设施故障。

## 结论摘要

本轮固定 100 道校准可运行题，90 道生成合法候选。Baseline 通过 87 道，Agent 最终通过 89 道，端到端净增益为 **2 个百分点**。只有 3 道合法候选在初始验证失败，全部进入工具修复，恢复 2 道。

两个成功修复均只补充寄存器初始化，适配参考实现中存在、但公开题面未明确写出的初值约定。唯一未恢复的双边沿题暴露了推理预算耗尽、无实质变化的修改、以及波形摘要无法直接展示采样瞬间事件顺序的问题。因此结果支持“本轮工具闭环能执行并修复部分错误”，不支持“已证明对复杂逻辑有显著、可泛化的增益”。

所谓“不合法候选”需要拆开：10 道生成失败中，8 道只有推理、没有最终代码；1 道流连接中断；只有 1 道提供了完整代码却不符合单模块提交约束。另有 12 道校准排除项在正式 100 题之外，不能混作模型答错。

## Agent 增益为何有限

1. **真正的工具修复机会只有 3 个。** 90 个合法候选中已有 87 个初始通过；固定 100 题中另 10 个在生成门槛前失败，不会进入当前 Agent 修复。只改进现有候选的修复环节，即使 3/3 全部修好，本轮上限也只是 90/100，而非 100/100。
2. **两次增益集中于初始化约定。** Prob104 从 1/199 失配到 0/199，Prob034 从 1/41 到 0/41，两者均只增加 `initial` 赋值并通过综合。说明可见反馈有用，但还没有复杂状态机修复的正面案例。
3. **Prob078 的反馈无法直接呈现错误采样点。** 真实失败在时钟边沿，VCD 摘要只给同一时间戳结束后的稳定值。模型实际收到 93/224 失配及首次时间 10，但附近摘要已经相等；公开警告说明了采样口径，却不能补出缺失的事件区域数据。
4. **长推理不等于有效动作。** Prob078 的 4 次正常请求耗尽 16384 token 后，强制动作恢复产生工具请求；前三轮语义修改中前两轮不改善时序行为，第三轮 XOR 反馈方案退化，均被验证后回退。精确重复被拒绝一次，但空白变化绕过源字节哈希去重，仍消耗修复轮次。
5. **证据/归因门禁不是本轮剩余失败的主要原因。** 3 个初始失败都符合 FUNCTIONAL_MISMATCH，均请求修复、接受修改并重新验证，漏斗中没有策略阻塞。不能继续用上一轮的门禁问题解释本轮全部结果。

## 下一轮优先验证

以下建议未在本次冻结测试中途实施，也未因此新增收费调用。

1. 先改进候选完成率：为“只有 reasoning、正文为空”设计独立的有界输出恢复对照，并把单模块要求写得更明确；分别报告合法率、功能通过率、调用数，不能用重采样增加后仍称单次结果。
2. 改进采样证据：输出与 TB 实际检查事件绑定的 expected/actual 和事件区域说明，保留时间戳末 VCD 作为补充，不假定两者相同。明确公开规范与初始化约定，并审查参考 X 的不约束行为。
3. 控制无效修改：先只识别纯空白变化和明确重复提交，记录修复假设及验证结果，避免把新的源字节哈希当成新的逻辑方案；不要未经验证就扩大为复杂的语义等价判定。
4. 使用独立保留集，并补充预先标注的错误修复集，增加真正的失败机会。反馈、技能、推理模式和预算分别做消融；本轮不是它们各自贡献的因果对照，也不能外推到完整 156 题总体。

结论边界：这是经过接口和评测器校准过滤、部分保留既往开发题的固定样本；`full_os_isolation_verified=false`。结果证明本批次在记录的配置下完成，不是普遍准确率、安全隔离或跨版本因果增益的保证。
