# Agent Note: P10 有界恢复与最佳观测版本

Status: implemented

[English](2026-09-21-p10-repair-v2.md) | 中文

## Problem

仅有 reasoning 的截断可能耗尽修复机会，却没有工具行动。只按严重级别解析会丢弃有价值的 XSim 提示。从更坏的候选继续修改会累积退化，而缺失证据不能安全地排成设计错误。

## Decision

[P10 修复协议](../../../../rtl-tools/phase1/p10/README.zh.md#repair-v2) 分离正常与仅行动输出预算，使用确定性的事实核心压缩已完成历史，保留有界 XSim 和 VCD 观测，并在继续修复前恢复绑定最佳证据的版本。所有模型可见输入在派发前持久化。不需要改变共享 provider 或已发布的 session schema。

本决策扩展而不替代[修复可达性](../bug-fix/2026-09-20-p10-repair-reachability.zh.md) 和[传输证据](../bug-fix/2026-09-21-p10-transport-evidence.zh.md)。相同 wire 重试记账、历史批次不可变及接受编辑后必须验证的要求继续有效。修复提示和预算变化要求新的批次冻结，不会追溯改变历史结果的策略。

## Alternatives considered

**只扩大 token 上限。** 更多输出容量本身不强制行动。有界恢复请求关闭 reasoning，并拒绝没有恰好一个完整合法工具调用的响应。现有 provider 接口无法强制工具选择或实现流内 reasoning token 截止点。

**让另一个模型总结证据。** 这会增加成本并引入未证实的解释。确定性 compact 保留源码、绑定、观测失败和拒绝版本，不将模型假设变成证据。

**按失配比例排序所有失败。** 编译失败、缺失证据和不同样本数并非可比较的比例。阶段排序只用于完整的设计证据；不可比较时恢复原最佳版本并停止。

**解析私有 WDB 或从 VCD 推断采样值。** 已有 XSim VCD 和原始提示足以提供有界时间戳窗口。时间戳末尾的值不能证明 testbench 的采样值、周期或根因，因此不作这些断言。

## Consequences

搜索策略有意不跨越打平或更差的中间版本。被拒绝源码及结果保留供检查，只有完整验证过的当前源码才能作为 PASS 导出。compact 和恢复后，模型、活动时长及工具步数限制仍有效。可选波形缺失不使独立判定证据失效。

## Testing

定向测试覆盖恢复输出预算、reasoning-off wire 字段、非法及半截动作拒绝、保留绑定的上下文超限恢复、退化回退、重复坏源码和有界波形观测。模型可见反馈快照记录确定性投影。Prob078 与 Prob104 历史证据通过只读回放检查；真实 provider 修复收益和新的 Vivado 运行需要单独冻结批次，不能由这些测试证明。
