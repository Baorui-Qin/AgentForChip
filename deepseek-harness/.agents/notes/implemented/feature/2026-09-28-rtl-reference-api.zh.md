# Agent Note：纯题面 RTL API 开发

状态：已实施

[English](2026-09-28-rtl-reference-api.md) | 中文

## 问题

研究 P10 依赖冻结的题目身份与可信裁判。将这类反馈作为参赛输入，会暴露公开规格中不存在的信息。API 开发期间无法使用本地模型部署，而保持不变的参考基线不能自行附加云端凭据。

## 决策

[参考适配器](../../../../rtl-tools/reference/README.zh.md)围绕已有 Agent 循环组装独立的最小 profile。模型唯一工具接受完整 RTL 文本，执行公开接口、语法及 DUT 独立综合检查。共享的纯接口解析器保持研究行为，不把研究数据导入解题器。提供方和模型来自配置；参赛路径不导入 DeepSeek tokenizer，也不设置 reasoning effort。

流接收包装器要求原始 JSON 完整且终止成功，之后才允许循环收到可调用工具。即使拒绝接收，包装器也会记录原始数据块。请求仍由 Session 历史派生；精确请求、Session 事件与候选哈希提供审计证据。独立回环转发端添加凭据，不改写基线提示词或采样，并约束两条路径的实际请求总数。

## 考虑过的替代方案

**放宽 P10 最终验收。** 否决，因为外部裁判候选与研究 VERIFIED 产物是不同结论。P10 验收保持不变。

**另建 Agent 循环。** 否决，因为已有循环已经负责工具分发、取消和 Session 重建。参考驱动仅提供受限工具、预算及发布规则。

**将工作目录称为操作系统沙箱。** 否决，因为 Windows ACL 提供方限制写入而非读取。开发模式明确报告能力级隔离，并要求显式启用。它不是生产裁判隔离。

## 影响

API 运行产生未评分候选，不产生隐藏功能结论。没有已检查候选的纯文本响应及失败运行产生空答案。严格源码子集排除了可访问文件的指令、字符串、外部代码与系统任务；有意牺牲通用 SystemVerilog 兼容性。字节限制不是 tokenizer 校准。API trace 不能证明本地权重身份、GPU 显存、离线就绪或比赛成绩。原版基线保持为包外不可变产物。

## 测试

聚焦真实循环测试覆盖未知题名、单工具请求快照、原始 JSON 拒绝、截断、取消、错误及请求大小/次数上限。HTTP 转发 fixture 验证请求体不变、实际指定模型元数据、不含秘密的账本与预算拒绝。研究负例回归覆盖共享解析器。真实 API 和本地 EDA 冒烟证据在仓库外维护；操作系统读取隔离及本地 Qwen 资源验收仍是独立前提。
