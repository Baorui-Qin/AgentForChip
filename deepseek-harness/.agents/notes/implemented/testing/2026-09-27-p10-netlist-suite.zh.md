# Agent Note: 已校准的 VerilogEval 网表规则

Status: implemented

[English](2026-09-27-p10-netlist-suite.md) | 中文

## 问题

仅按题名启用网表检查器，会使未测试的时序适配器成为评分依据。RTL 测试台调度、FPGA 启动和仅参考实现具有的初始化，也可能拒绝正确硬件或接受空比较。

## 决策

[构建器](../../../../rtl-tools/src/phase1/p10-netlist-suite.ts) 从固定数据集字节派生仅 Host 使用的参考比较器，不依赖上游 RTL 比较进程。激励反馈观察参考输出而非候选输出。激励局部的显式随机种子消除展开层级引起的随机序列变化。启动等待 GSR/GTS 释放；数据跨时钟事件保持，采样避开 UNISIM 稳定过程。物理时钟及已审查的锁存器使能不随数据延迟。过程块开头的声明保留合法作用域。

参考 X/Z 位明确不构成断言，也不计为成功比较。每个必检输出位必须至少出现一次已知值；参考已知位拒绝 DUT 的 X/Z。仅 Prob094 公开未规定的 `out_both[3]` 和 `out_any[0]` 豁免观察。即使失配数为零，实时验收和独立收据审计也会拒绝覆盖错误标记。检查次数来自新运行的参考 RTL 对照，网表执行必须匹配。有限比较不证明参考规格正确或未观察行为。

异或反馈题使用公开递推关系，而非隐藏参考实现的初值零约定。它允许任一已知初始状态，之后独立检查状态转换与保持。初值零和初值一的综合对照均通过。其负例使用恒零输出，因为在初态不受约束时，输出反相仍满足该递推关系。

[校准器](../../../../rtl-tools/phase1/p10/calibrate-netlists.mjs) 不调用模型，保留冻结输入、正例、输出故障注入负例及原始工具证据。归档网表仅为只读对照输入，不继承旧 PASS；必须执行新检查器，失败还会触发参考实现重新综合。[发布器](../../../../rtl-tools/phase1/p10/publish-netlist-profiles.mjs) 独立审计证据后才生成启用规则。替换校准必须显式列出题目，并保留被替代批次目录和规则哈希。规则选择绑定题目、公开题面和数据集哈希；未知或矛盾接口保持拒绝。

[RT-01 验收决策](../bug-fix/2026-09-27-p10-netlist-acceptance.zh.md) 继续负责候选策略、收据以及 Baseline/Agent 共用评分。本决策替代其三题覆盖限制，不替代验收协议。[RTL 兼容性决策](../bug-fix/2026-09-18-p10-reviewed-compatibility.zh.md) 继续有效；网表校准不修复该评测器的调度问题。

[公开接口勘误](../../../../rtl-tools/src/phase1/p10-interface-errata.ts) 将用户明确批准绑定到精确题面哈希，不读取参考实现：Prob031 的 `q` 为输出，Prob062 的 `out` 为八位。新目录、校准溯源及记录的生成/修复约束携带相同解释；原始文本和历史目录保持不变。规则选择拒绝缺失或变更的勘误元数据。校准单独冻结有效目录，不编辑历史文件。这避免评测器使用修正接口，而任一模型组仍只收到矛盾题面。

## 考虑过的替代方案

**立即启用所有生成的测试台。** 生成成功不代表调度有效或比较器可用。只有完成真实工具正负例校准才能发布。

**复用上游比较进程或将未知值视为相等。** 两者都不能确定 FPGA 启动后的硬件行为。稳定采样与逐位观察要求拒绝空证据，也不为参考 X/Z 虚构预期值。

**从参考答案推断矛盾的公开接口。** 隐藏答案不能静默修正公开题目。矛盾题保留可见阻塞，等待独立审查勘误。

**每次重新综合对照。** 新参考 RTL 检查与独立重核哈希的归档综合产物共同降低校准开销。新综合仍为回退路径；历史模型输出不成为真值或新模型成绩。

## 后果

生成规则可复现、绑定数据集并可审计。测试覆盖注释安全改写、过程作用域、时钟保持、未知位处理、哈希绑定及发布失败；真实 Vivado 对照保留为外部证据。规则包含可信参考内容，仅供 Host 使用。仅已批准的公开勘误进入模型提示，无密钥快照验证生成与修复的任务信息一致；不增加修复预算或隐藏测试反馈。输出故障注入证明比较器敏感性，不代表全面变异覆盖。形式等价、参考实现正确性及 RT-02 仍需独立处理。
