# Agent Note: 冻结的全数据集 P10 兼容套件

Status: implemented

[English](2026-09-18-p10-full-compat-suite.md) | 中文

## Problem

按题维护的兼容白名单不能清点完整基准。在评分过程中修改共享评测器，也会使并发结果和验证缓存产生歧义。

## Decision

[完整套件构建器](../../../../rtl-tools/src/phase1/p10-compat-suite.ts) 仅在 worker 启动前由 Host 执行。固定 Git 目录提供预期原字节哈希。保守结构规则识别完整已知模块前缀及唯一声明对，保留其他所有字节。确定性清单包含每道题，包括未修改输入和待人工审查项。显式构建时间让来源时间戳可以复现，而不依赖每次执行的墙钟时间。

真实代表题的正负例校准先于只读封存。Worker 将固定字节加载到独立快照中，不调用转换器，并把套件身份绑定到现有验证输入。探针失败保留为证据；缺省 timescale 是独立 Host 策略，不覆盖显式单位。正确和错误 DUT 都必须有可观察结果，才能报告评测器就绪。信息性版本命令采用现有允许退出码约定，实际 EDA 命令仍要求退出码为零。

[十一题决策](2026-09-18-p10-reviewed-compatibility.zh.md) 仍负责其精确哈希适配器和模型编排。完整套件模式单独构建和校准，不自动扩展该白名单。Agent、提示词、技能和模型设置保持不变。

## Alternatives considered

**跨文件宽泛替换。** 拒绝，因为匹配文本可能位于其他模块或预处理分支。保守误拒需要人工审查，而不是推测性重写。

**验证过程中转换。** 拒绝，因为共享可变字节会产生竞争，破坏可复现评测器身份。

**把转换成功或仅正例通过当作就绪。** 拒绝，因为静态可移植性与错误 DUT 检测是独立结论。未执行的题不推断工具判定。

## Consequences

测试覆盖可逆两行变动、预期哈希、作用域歧义、重复转换、LF/CRLF、上游不变和确定性输出。真实 Vivado 记录覆盖代表题校准及冻结后的固定十题预检。只读权限对 worker 身份进行验证，不宣称能抵御管理员。原始 Icarus 交叉对照要求已安装该工具。规则变化需要新的套件身份与校准；不同评测器版本的模型成绩不能合并。
