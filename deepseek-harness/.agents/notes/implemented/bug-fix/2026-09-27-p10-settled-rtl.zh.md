# Agent Note：稳定采样 RTL 评测

状态：已实现

[English](2026-09-27-p10-settled-rtl.md) | 中文

## 问题

网表验收不能修复误导性的 RTL 反馈。上游 delta-cycle 比较进程可能拒绝正确双沿设计、接受错误修复。在网表验收前将该结论反馈给 Agent，会同时污染修复轨迹和 Baseline 比较。

## 决策

[稳定 RTL 评测器](../../../../rtl-tools/src/phase1/p10-settled-rtl.ts) 从[已校准硬件 oracle](../testing/2026-09-27-p10-netlist-suite.zh.md) 派生独立版本的测试平台。RTL 与网表使用相同激励和采样时序，仅 FPGA 专用启动断言和完成报告不同。精确样本数及输出观察要求防止不完整比较被判成功。

冻结清单显式选择协议。两组模型加载相同测试平台字节、已批准公开接口及原始资产身份。元数据无效时不回退到旧评测器。既有批次文件和成绩保持不变；比较新评测器需要新候选和新冻结。参考代码仅供 Host 使用，不进入模型输入。

无模型校准器通过真实工具链执行正确及故障 RTL，记录所有结果。可选重放用源码哈希绑定历史正确及错误候选。原始仿真日志、VCD、冻结测试平台字节和清单哈希保留供审计。日志的首次失配时间是观察结果，不是推断的采样值或诊断。

## 影响

有限仿真不能证明形式等价或符合公开规格。两项检查复用同一 oracle 可保持采样一致，但不构成独立参考验证。已知参考冲突仍在实验报告中披露。旧评测器保留用于读取历史批次，不赋予新协议结果任何效力。可选有界波形提取不可用时，仍保留原始 VCD 证据。

## 考虑过的替代方案

保留原 RTL 比较进程而只添加网表验收，仍会让错误反馈驱动修复。编辑已冻结历史测试平台会破坏实验身份。独立 RTL 协议保留证据并统一新评分，代价是需要新校准和新批次，不能复用旧成绩。

## 验证

所属目录快照测试覆盖派生测试平台文本和清单路由；清单或测试平台变化均拒绝执行。真实 Vivado 对照验证正例接受、故障 DUT 拒绝及未观察必检输出时的拒绝。RT-02 历史重放接受原始正确 Prob078 设计、拒绝历史错误 PASS。每道新评分题均要求独立冻结的正负例校准。
