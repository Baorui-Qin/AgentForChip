# Agent Note: 经审查的 P10 评测器移植

Status: implemented

[English](2026-09-18-p10-reviewed-compatibility.md) | 中文

## Problem

冻结评测器的声明顺序错误阻止候选测量。让参赛模型修改评分器会破坏结果有效性，但禁止独立受审查的开发期移植同样会阻止有效评测。

## Decision

[兼容适配器](../../../../rtl-tools/src/phase1/p10-compat.ts) 是 Host 专用、精确哈希白名单变换。它保留原始字节行，记录逆置换及差异，绝不写入上游。派生身份、适配器身份、源列表、seed 和可选默认 timescale 通过快照 manifest 进入既有 verification key。校准与候选评分加载同一派生文件。默认 timescale 处理已观察的展开错误，不改变显式 TB 时间单位或综合时钟约束。

[P10 模型入口](../../../../rtl-tools/src/phase1/p10-model.ts) 将单次生成、Host 评分与有界 P09 工具修复分开。共享生成只消耗一次物理派发；错误种子修复校准单独标记，不增加对照成绩。当前候选、验证与导出哈希必须一致。原无模型预检保留 LLM 拒绝。Reference 依赖拒绝补充仅 DUT 综合，但不构成 OS 沙箱。

## Alternatives considered

**修改数据集或放宽诊断。** 拒绝，因为这会掩盖评测器变化和真实错误。新批次保留失败前驱证据。

**把校准当成候选 PASS。** 拒绝，因为参考转接只证明评分器健康，不证明模型综合或公开题面正确性。

**自动推广规则到所有任务。** 拒绝，因为模板相似不等于审查精确输入。扩展需要单独审查哈希并获得可观测负例。

## Consequences

单独构建的[全数据集套件](2026-09-18-p10-full-compat-suite.zh.md) 负责结构扫描和封存后的运行期加载，不改变本文的精确哈希适配器及模型编排。

定向测试覆盖字节可逆、作用域变化、重复声明、未知哈希和借用 reference。真实 Vivado 正负例仍是必要证据。模型协议遇到格式或传输错误即停止，不静默重试。不声称官方隐藏评分、跨仿真器等价或完整 OS 隔离。四十题授权前必须完成十题审计；不替换不支持的资产。
